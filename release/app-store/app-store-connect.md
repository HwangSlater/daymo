## 5. 연령 등급 질문

App Store Connect → 앱 정보 → 연령 등급. 2026-09 질문지 기준이다. 예상 등급은 **4+**.
이용약관은 만 14세 이상만 가입하게 하지만, App Store 등급은 앱 안 콘텐츠를 기준으로 매긴다.

| 질문 | 답 | 이유 |
| --- | --- | --- |
| 보호자 통제(Parental Controls) | 없음 | |
| 연령 확인(Age Assurance) | 없음 | 가입 때 만 14세 이상인지 스스로 확인받을 뿐 확인 수단은 없다 |
| 제한 없는 웹 액세스 | 없음 | 앱 안에서 임의의 웹을 둘러볼 수 없다. 약관·로그인·지도 링크는 정해진 주소만 연다 |
| 사용자 생성 콘텐츠 | **있음** | 초대받은 멤버끼리 사진·메모·일기를 본다. 공개 피드는 없다 |
| 소셜 미디어 | 없음 | 피드·팔로우·공개 공유가 없다 |
| 메시지 및 채팅 | 없음 | 사람끼리 대화하는 기능이 없다(메모는 여행에 붙는 기록) |
| 광고 | 없음 | |
| 욕설·공포·음주/약물·의료·선정성·폭력·총기 | 모두 없음 | 앱이 제공하는 콘텐츠가 없다. 사용자가 올리는 것은 위 사용자 생성 콘텐츠로 답했다 |
| 도박·모의 도박·경품·루트박스 | 모두 없음 | 정산은 기록·계산만 하고 돈을 걸거나 보내지 않는다 |

## 6. 앱 개인정보 보호 (App Privacy)

App Store Connect → 앱 개인정보 보호 → 시작하기.

**데이터 수집 여부:** 예, 이 앱에서 데이터를 수집합니다.
**추적(Tracking):** 모든 항목에서 "아니요". 다른 회사 데이터와 연결하지 않고 광고를 하지 않는다.

| Apple 데이터 유형 | 수집 | 용도 | 사용자와 연결 | 추적 |
| --- | --- | --- | --- | --- |
| 연락처 정보 → 이메일 주소 | 예 | 앱 기능 | 예 | 아니요 |
| 연락처 정보 → 이름 | 예 | 앱 기능 | 예 | 아니요 |
| 사용자 콘텐츠 → 사진 또는 비디오 | 예 | 앱 기능 | 예 | 아니요 |
| 사용자 콘텐츠 → 기타 사용자 콘텐츠 | 예 | 앱 기능 | 예 | 아니요 |
| 식별자 → 사용자 ID | 예 | 앱 기능 | 예 | 아니요 |
| 식별자 → 기기 ID | 예 | 앱 기능 | 예 | 아니요 |
| 위치 → 정확한 위치 | **정할 것에 따라** | 앱 기능 | 예 | 아니요 |

- **정확한 위치:** 사진 원본의 GPS를 지우지 않고 제출하면 "예"로 신고한다. 지우기로 하면 신고하지 않는다(release/README.md).
- 기기 ID는 앱이 만든 설치 식별값이다. 광고 ID(IDFA)를 쓰지 않는다.
- 신고하지 않는 것: 결제 정보, 건강, 금융 정보(정산 기록은 사용자가 적은 금액이라 "기타 사용자 콘텐츠"에 포함), 연락처 목록,
  검색 기록, 브라우징 기록, 사용 데이터, 진단(오류 수집 SDK 없음), 민감한 정보.
- 보안 목적의 서버 접속 기록(IP)은 Apple 데이터 유형 목록에 해당 항목이 없어 따로 신고하지 않고 처리방침에 적는다.
  제출 직전에 Apple의 "App privacy details" 도움말로 한 번 더 확인한다.

## 8. 수출 규정 준수

`mobile/app.json` 의 `ios.config.usesNonExemptEncryption: false`. HTTPS 등 운영체제가 제공하는 표준 암호화만 쓴다.
빌드에 `ITSAppUsesNonExemptEncryption = NO` 가 들어가 제출할 때 따로 묻지 않는다.

## 9. 권한 문구 (Info.plist)

| 키 | 값 |
| --- | --- |
| NSPhotoLibraryUsageDescription | 여행 사진을 기록에 추가하려면 사진 접근 권한이 필요합니다. |

앱은 시스템 사진 선택 창(PHPicker)을 써서 권한을 묻지 않지만, 모듈이 넣는 문구라 한국어로 둔다. 카메라·마이크·위치·Face ID 문구는 없다
(2026-09-15 `npx expo config --type introspect` 로 확인).
