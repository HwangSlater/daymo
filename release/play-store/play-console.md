## 5. 데이터 보안 (Data safety)

**데이터 수집·공유:** 수집함. 제3자와 공유하지 않음(서버 운영·메일 발송 위탁은 공유에 해당하지 않는다).
**보안 관행:** 전송 중 암호화 — 예 / 사용자가 데이터 삭제를 요청할 수 있음 — 예 / 독립 보안 검토 — 아니요.

| Google 데이터 유형 | 수집 | 공유 | 일시적 처리 | 필수/선택 | 목적 |
| --- | --- | --- | --- | --- | --- |
| 개인 정보 → 이름 | 예 | 아니요 | 아니요 | 필수 | 앱 기능, 계정 관리 |
| 개인 정보 → 이메일 주소 | 예 | 아니요 | 아니요 | 필수 | 앱 기능, 계정 관리, 개발자 커뮤니케이션(인증·삭제 안내 메일) |
| 개인 정보 → 사용자 ID | 예 | 아니요 | 아니요 | 필수 | 앱 기능, 계정 관리 |
| 사진 및 동영상 → 사진 | 예 | 아니요 | 아니요 | 선택 | 앱 기능 |
| 앱 활동 → 기타 사용자 생성 콘텐츠 | 예 | 아니요 | 아니요 | 필수 | 앱 기능 |
| 기기 또는 기타 ID | 예 | 아니요 | 아니요 | 필수 | 앱 기능, 사기 방지·보안(로그인 기기 관리) |
| 위치 → 정확한 위치 | **정할 것에 따라** | 아니요 | 아니요 | 선택 | 앱 기능 |

- **정확한 위치:** 사진 원본의 GPS를 지우지 않으면 "수집: 예"로 신고한다(release/README.md).
- 수집하지 않음: 금융 정보(결제·카드·신용), 건강, 메시지(이메일·SMS·앱 내 메시지), 오디오, 파일, 캘린더, 연락처, 앱 상호작용·검색 기록·
  설치된 앱, 웹 기록, 비정상 종료 로그·진단.
- 보안 목적의 서버 접속 기록(IP)은 처리방침에 적었다. 데이터 보안 양식에서 신고 대상인지는 제출 직전에 Play Console 도움말
  "데이터 보안 섹션에 정보 제공"을 다시 확인한다.

## 6. 권한

릴리스 매니페스트에는 `INTERNET`, `VIBRATE` 만 남는다(`mobile/app.json` `android.blockedPermissions`, 2026-09-15
`npx expo config --type introspect` 로 확인). 사진은 Android 사진 선택 도구로 고른 것만 받아 사진·동영상 권한 선언이 필요 없다.

```
데모 계정에는 예시 공간과 여행이 들어 있습니다. 여행을 누르면 일정·장소·준비·요리·비용·기록 탭을 볼 수 있습니다.
계정 삭제: 우리 → 내 프로필 → 계정 삭제.
정산 기능은 계산과 기록만 하며 실제 송금이나 결제를 하지 않습니다.
```
