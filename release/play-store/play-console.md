## 4. 콘텐츠 등급 (IARC 질문지)

| 질문 | 답 |
| --- | --- |
| 이메일 | support@daymo.xyz |
| 카테고리 | **다른 모든 앱 유형**(2026-09 콘솔 선택지: 게임 / 소셜 또는 커뮤니케이션 / 다른 모든 앱 유형. 기본 목적이 여행 기록이라 소셜이 아니다) |
| 폭력·성·언어·약물·도박 콘텐츠 | 모두 아니요 |
| 사용자끼리 콘텐츠를 주고받거나 상호작용할 수 있음 | **예** (초대받은 멤버끼리 사진·메모를 본다) |
| 사용자 위치를 다른 사용자와 공유 | 아니요 |
| 디지털 상품 구매 | 아니요 |
| 무작위 아이템(루트박스) | 아니요 |

받은 결과(2026-09-22): 한국 12세 이상, IARC 만 12세 이상·ESRB 청소년·PEGI 부모 지도 요망, 모두 「사용자 상호작용」 표시.
「사용자가 만든 공유 콘텐츠가 주요 출처」에 예라고 답하면 IARC 가 12세로 올린다. 약관 가입 연령(만 14세)보다 낮아 따로 고칠 것은 없다.
그 밖의 질문 답: 노출(nudity) 공유 아니요, 생생한 폭력 아니요, 차단 예, 신고 예, 채팅 조정 아니요(채팅 없음), 초대된 친구로 제한 예,
현금 보상·NFT 아니요, 브라우저·검색 아니요, 뉴스·교육 아니요. 유료 기능을 켜면 「디지털 상품 구매」를 예로 바꿔 다시 받는다.

## 5. 데이터 보안 (Data safety)

**데이터 수집·공유:** 수집함. 제3자와 공유하지 않음(서버 운영·메일 발송 위탁은 공유에 해당하지 않는다).
**보안 관행:** 전송 중 암호화 — 예 / 사용자가 데이터 삭제를 요청할 수 있음 — 예 / 독립 보안 검토 — 아니요.

| Google 데이터 유형 | 수집 | 공유 | 일시적 처리 | 필수/선택 | 목적 |
| --- | --- | --- | --- | --- | --- |
| 개인 정보 → 이름 | 예 | 아니요 | 아니요 | 필수 | 앱 기능, 계정 관리 |
| 개인 정보 → 이메일 주소 | 예 | 아니요 | 아니요 | 필수 | 앱 기능, 계정 관리, 개발자 커뮤니케이션(인증·삭제 안내 메일) |
| 개인 정보 → 사용자 ID | 예 | 아니요 | 아니요 | 필수 | 앱 기능, 계정 관리 |
| 사진 및 동영상 → 사진 | 예 | 아니요 | 아니요 | 선택 | 앱 기능 |
| 앱 활동 → 기타 사용자 생성 콘텐츠 | 예 | 아니요 | 아니요 | 필수 | 앱 기능 |
| 기기 또는 기타 ID | 예 | 아니요 | 아니요 | 필수 | 앱 기능, 사기 방지·보안(로그인 기기 관리) |
| 앱 정보 및 실적 → 비정상 종료 로그 | 예 | 아니요 | 아니요 | 필수 | 앱 기능(오류 진단) |

- **위치:** 수집하지 않음. 사진 속 GPS는 서버가 저장 전에 원본에서도 지운다(2026-09-15 결정).
- **비정상 종료 로그**는 "수집함, 필수"다. 앱 안에 끄는 스위치가 없어 사용자가 고를 수 없으므로 선택이 아니다(2026-09-22 바로잡음). 앱에 오류 수집 SDK는 없지만, 앱이 멈추면 오류 종류·한 줄 설명·어느 화면인지·플랫폼·앱 버전을 Daymo 서버로 보낸다(`POST /v1/client-errors`). 계정이나 토큰을 함께 보내지 않는다. `EXPO_PUBLIC_DAYMO_ERROR_REPORT=off` 로 끈 빌드에서는 이 줄을 뺀다. 같은 범주의 "진단"과 "기타 앱 실적 데이터"는 수집하지 않는다. 서버는 이 한 줄을 2026-09-17부터 Sentry(미국, 보관 30일)로도 올린다 — 우리를 대신해 처리하는 수탁자라 "공유"에는 해당하지 않는다고 보았다.
- 수집하지 않음: 금융 정보(결제·카드·신용), 건강, 메시지(이메일·SMS·앱 내 메시지), 오디오, 파일, 캘린더, 연락처, 앱 상호작용·검색 기록·
  설치된 앱, 웹 기록, 진단.
- 보안 목적의 서버 접속 기록(IP)은 처리방침에 적었다. 데이터 보안 양식에서 신고 대상인지는 제출 직전에 Play Console 도움말
  "데이터 보안 섹션에 정보 제공"을 다시 확인한다.

## 6. 권한

릴리스 매니페스트에는 `INTERNET`, `VIBRATE` 만 남는다(`mobile/app.json` `android.blockedPermissions`, 2026-09-15
`npx expo config --type introspect` 로 확인). 사진은 Android 사진 선택 도구로 고른 것만 받아 사진·동영상 권한 선언이 필요 없다.

## 7. 앱 액세스 권한 안내 (심사용)

```
로그인이 필요한 앱입니다. 아래 데모 계정으로 로그인해 주세요.
아이디: (데모 계정 이메일)
비밀번호: (데모 계정 비밀번호)

데모 계정에는 예시 공간과 여행이 들어 있습니다. 여행을 누르면 일정·장소·준비·요리·비용·기록 탭을 볼 수 있습니다.
계정 삭제: 우리 → 내 프로필 → 계정 삭제.
정산 기능은 계산과 기록만 하며 실제 송금이나 결제를 하지 않습니다.
```
