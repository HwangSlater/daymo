# 스크린샷과 그래픽 이미지

두 스토어 모두 **실제 앱 화면**이어야 한다. 화면은 기기에서 찍은 그대로 쓰고, 둘레에 휴대폰 모형과 대화 말풍선만 두른다.
모형은 스크립트가 그린다(남의 기기 사진을 쓰지 않는다). 화면 안의 내용은 고치지 않는다 — 손대는 것은 기기의 상태 표시줄과 아래 버튼 막대뿐이다.
데모 계정(예시 이름·예시 여행)으로 찍는다. 실제 사람 이름·연락처가 보이면 안 된다.

## 규격

| 스토어 | 크기 | 장수 | 비고 |
| --- | --- | --- | --- |
| App Store | 1290×2796 원본 / 1284×2778 업로드 사본 | 10장 | App Store Connect가 1242×2688 또는 1284×2778을 요구하는 칸에는 업로드 사본을 쓴다. `~/Downloads/daymo-미리보기/스토어-최종/앱스토어-캡션-1284x2778` |
| Google Play 스크린샷 | 1080×2160 | 8장 | 긴 변이 짧은 변의 2배를 넘으면 안 된다. 요즘 폰 화면(1080×2340)은 넘어서 모형에 넣어 2:1 로 맞춘다 |
| Google Play 그래픽 이미지 | 1024×500, 투명 없음 | 1장 | `release/assets/play-feature-graphic.png` |

## 화면과 대화

이미지 위쪽은 멤버끼리 나누는 카톡 같은 대화(말풍선)이고, 아래는 그 답이 보이는 앱 화면이다(`scripts/store_chat.py`).
광고 문구 대신 실제로 오갈 법한 말을 쓴다. 기능 이름을 설명하지 않고, 답은 화면에 보이는 값과 맞춘다.
첫 장이 목록에 제일 크게 걸리므로 홈이 맨 앞이다.

| 화면 | 어떻게 가는지 | 묻는 말 / 답 | 짚는 방식 | App Store | Play |
| --- | --- | --- | --- | --- | --- |
| 홈 | 로그인 직후 | 여울: 우리 체크인 몇 시더라? / 15일 오후 3시! | 체크인 칸을 꺼냄 | 01 | 01 |
| 일정 | 여행 카드 → 「일정」 탭 | 가람: 올라오는 버스 몇 시였지? / 2시 버스. 4시 40분 도착 | 교통편에 테두리만 | 02 | 02 |

Play 는 8장까지라 찾기·우리를 뺐다.

- **꺼냄**: 답이 작은 글자·숫자라 폰 안에서 안 읽히는 화면. 그 자리를 테두리로 짚고, 같은 카드를 크게 잘라 폰 위에 얹는다.
- **테두리만**: 사진처럼 폰 안에서도 잘 보이거나, 꺼내면 다른 내용을 가리는 화면.
- 자르는 경계는 화면 속 카드 가장자리를 픽셀로 잰 값이고, 꺼낸 조각의 모서리 둥글기도 원래 카드에 맞춘다.
  다시 찍으면 `store_chat.py` 위쪽의 자리 값을 다시 잰다(아이폰·갤럭시 따로).

### 화면에 보여야 하는 것

빈 목록이 찍히면 그 탭이 무엇을 하는 곳인지 드러나지 않는다. 데모 계정(`app/jobs/seed_demo.py`)은 이 조건을 만족하도록 채워 둔다.

- **준비**: 준비물이 여러 개이고 **일부만 체크**돼 있어야 한다. 전부 체크하면 「남은 준비」가 빈 화면이 된다.
- **기록**: 사진이 격자를 채울 만큼 있어야 한다. 씨앗이 만드는 단색 사진은 스토어에 쓰지 않는다.
- **캘린더**: 여행과 멤버 일정·메모가 같은 달에 여럿 보여야 한다.
- **비용**: 정산에 「누가 누구에게」 한 줄과 「지출 추가」 단추가 다 보여야 한다. 갤럭시는 아래 버튼 막대를 떼므로 그 위에서 잘리지 않았는지 본다.

## 찍는 법

2026-09-21 한 벌은 **Expo Go** 로 찍었다. 스토어 빌드가 없어도 앱 화면은 같다.

- 아이폰 16 Pro(1206×2622) — App Store 용. 측면 버튼 + 볼륨 올리기.
- 갤럭시 S21(1080×2340) — Play 용. 전원 + 볼륨 내리기.

찍기 전에:

1. 데모 계정으로 로그인한다(`shared/demo-account.md`). 실제 계정으로 찍지 않는다.
2. **밝은 모드**로 맞춘다. 한 벌이 같은 모드여야 한다.
3. 방해 금지를 켠다. 알림 배너가 지나간 장은 버린다.
4. 키보드·새로고침 표시가 없는지 본다. 배터리는 신경 쓰지 않아도 된다(아래에서 칠한다).

## 만드는 차례

스크립트는 `release/scripts/` 에 있다. 말풍선판(`store_chat.py`)만 playwright 를 쓰고 나머지는 Pillow 만 쓴다. 앱 글꼴(`mobile/assets/fonts/CookieRun-*`)을 그대로 쓴다.

1. **차례 적기.** 찍은 폴더에 `차례.txt` 를 두고 한 줄에 `01-홈 <파일이름>` 처럼 적는다. 나갈 파일이 `01-홈.png` 가 된다.
   아이폰에서 충전 중(초록·번개)으로 찍힌 장은 줄 끝에 `--charging` 을 붙인다.
2. **다듬기.** `store_prepare.py` 가 기기 흔적만 걷어 낸다.
   - 아이폰: 폭 1290 으로 줄이고 아래를 떼어 1290×2796 에 맞춘다. 배터리를 가득 찬 모양으로 칠한다. 검은 바탕 화면은 상태 표시줄 줄을 바탕색으로 덮는다.
   - 갤럭시: 아래 버튼 막대를 떼고(2196px 아래), 상태 표시줄(84px 위)을 바탕색으로 덮는다.
   - 배터리·막대 자리는 위 두 기기를 잰 값이다. 다른 기기로 찍으면 스크립트 위쪽 상수를 다시 잰다.
3. **말풍선판.** `store_chat.py` 가 위에 대화를 얹고 아래에 휴대폰 모형을 두며, 답 자리를 짚는다. HTML 로 그려 Chromium 으로 찍기 때문에 `pip install playwright && playwright install chromium` 이 필요하다.
4. **그래픽 이미지.** `store_feature_graphic.py` 가 다듬은 아이폰 화면 중 캘린더·홈·추억카드 세 장을 모형에 넣어 오른쪽에 부채꼴로 세우고,
   왼쪽에 「Daymo / 연인·친구와 함께 쓰는 여행 노트 / 일정 · 준비물 · 비용 · 사진을 한 공간에」를 적는다.

```sh
cd release/scripts
python store_prepare.py iphone  <아이폰폴더>  <작업>/ip  <아이폰폴더>/차례.txt
python store_prepare.py galaxy  <갤럭시폴더>  <작업>/ga  <갤럭시폴더>/차례.txt
python store_chat.py  iphone  <작업>/ip  <나갈폴더>/app-store   # 1290x2796
python store_chat.py  galaxy  <작업>/ga  <나갈폴더>/play        # 1080x2160
python store_feature_graphic.py  <작업>/ip          # release/assets/play-feature-graphic.png 를 새로 쓴다
```

예전 캡션판(큰 제목 + 휴대폰 모형)은 `store_mockup.py`, 모형 없이 캡션만 얹는 판은 `store_compose.py` 로 만든다.

## 두는 곳

- 찍은 원본과 완성본은 **저장소에 넣지 않는다**(장당 1~3MB, 스토어에 올리면 끝이다). 운영자 PC 의 `daymo-미리보기\스토어-최종\` 에
  `원본\아이폰`, `원본\갤럭시`, `앱스토어-캡션-1290x2796`, `플레이-캡션-1080x2160` 으로 둔다.
- 저장소에는 스크립트와 그래픽 이미지(`release/assets/`)만 둔다.
- 옛 그래픽 이미지(아이콘 + 글자 배너)는 `python release/scripts/build-store-assets.py --old-banner` 로 다시 만들 수 있다.
