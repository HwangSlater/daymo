# Daymo 제품·개발 규칙

이 폴더는 Daymo를 계속 개발할 때 지켜야 할 현재 프로젝트 규칙과, 이후 다른
모바일 앱에도 재사용할 수 있는 공통 원칙을 분리해 기록한다.

- [현재 Daymo 개발 규칙](./01-daymo-development-rules.md)
- [다음 앱에도 적용할 공통 규칙](./02-reusable-app-development-rules.md)

## 적용 우선순위

1. 사용자가 현재 작업에서 직접 요청한 결정
2. `01-daymo-development-rules.md`의 Daymo 전용 규칙
3. `02-reusable-app-development-rules.md`의 공통 규칙
4. 기존 개발 및 UI 검토 문서

규칙과 구현이 충돌하면 임의로 구현을 진행하지 않고 충돌 내용과 선택지를 먼저
공유한다. 제품 방향이 바뀌면 코드와 함께 이 문서도 갱신한다.
