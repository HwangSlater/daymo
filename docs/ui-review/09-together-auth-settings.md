# 9단계 · 우리·로그인·설정

## 목표

현재 여행 공간과 함께하는 멤버, 내 계정과 앱 설정을 서로 혼동하지 않고 관리하며 권한 변경과 위험한 계정 동작을 안전하게 처리한다.

## 반영한 내용

- 현재 여행 공간 카드와 빠른 공간 탭에 선택 상태와 접근성 문구를 추가했다.
- 공간을 전환하면 멤버 관리 선택을 항상 내 계정으로 초기화한다.
- 최근 여행 행을 누르면 해당 여행 상세 화면으로 이동한다.
- 실제 공유 범위에 맞춰 `기록 내보내기`를 `여행 목록 공유`로 수정했다.
- 알림 빠른 설정을 접근성 스위치로 표현하고 현재 켜짐 상태를 전달한다.
- 멤버·공간·테마 선택 항목에 라디오 역할과 선택 상태를 추가했다.
- `보기만` 권한 설명에서 실제 권한과 모순되던 체크 가능 문구를 제거했다.
- 멤버 내보내기는 대상과 영향 범위를 표시한 확인창을 유지한다.
- 로그아웃 전에 기기 변경 내용 동기화를 확인할 수 있는 경고창을 추가했다.
- 계정 삭제를 로그아웃과 분리하고 되돌릴 수 없다는 영향 범위를 안내한다.
- 회원가입에서 이용약관과 개인정보 수집·이용을 필수 동의로 받는다.
- 여행 소식과 혜택 알림은 선택 동의로 분리했다.
- 모두 동의를 제공하되 선택 동의는 개별적으로 다시 해제할 수 있다.
- 필수 동의를 하지 않으면 회원가입 완료 버튼을 활성화하지 않는다.

## 권한 기준

- `관리자`: 공간, 멤버와 모든 여행 데이터를 관리한다.
- `편집 가능`: 일정·장소·준비·요리·기록을 함께 수정한다.
- `보기만`: 내용을 확인하지만 수정하거나 체크하지 않는다.
- 자기 자신은 멤버 내보내기 대상이 아니며 계정 화면에서 로그아웃 또는 계정 삭제를 사용한다.

## 화면 원칙

- 공간 전환, 공간 프로필, 멤버 관리와 내 프로필을 별도 진입점으로 둔다.
- 즉시 반영되는 테마·화면 모드와 되돌리기 어려운 멤버·계정 동작을 시각적으로 구분한다.
- 로그아웃과 계정 삭제는 같은 의미로 보이지 않게 분리한다.
- 필수 동의와 선택 동의를 문구에서 명확히 구분한다.

## 개발 단계로 넘기는 항목

- 소셜 로그인 제공자별 실제 OAuth 및 계정 연결 상태
- 이용약관·개인정보 처리방침 전문 화면과 버전별 동의 이력
- 만 14세 미만 가입 제한과 필요한 연령 확인 정책
- 알림·마케팅 동의의 서버 저장 및 변경 이력
- 계정 삭제 유예 기간, 재인증과 서버 데이터 삭제 작업
- 공간별 멤버·권한 서버 검증과 마지막 관리자 보호
- 초대 링크 만료, 사용 횟수와 승인 절차
- 내보내기 범위 선택과 개인정보 마스킹
