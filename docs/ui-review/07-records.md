# 7단계 · 기록

## 목표

여행 사진과 일기를 부담 없이 남기고, 저장한 기록을 다시 열어 고치거나 정리하며 한 장의 기념 카드로 간직할 수 있게 한다.

## 반영한 내용

- 기록 상단에 사진 수, 일기 수, 사진을 기록한 날짜 수를 요약한다.
- 사진 추가 버튼을 누르면 바로 임시 항목을 만들지 않고 사진 선택 화면을 먼저 연다.
- 사진을 선택한 뒤 여행 날짜와 짧은 설명을 함께 저장할 수 있다.
- 저장한 사진 카드를 눌러 날짜와 설명을 수정하거나 사진을 삭제할 수 있다.
- 사진 카드에서 무의미한 일련번호 대신 사진 설명과 여행 날짜를 보여 준다.
- 일기 카드를 눌러 제목과 본문을 수정하거나 일기를 삭제할 수 있다.
- 일기 추가와 수정 상태에 맞춰 완료 버튼 문구를 구분한다.
- 기념 카드 제목을 현재 여행명으로 만들고 날짜도 현재 여행 기간을 사용한다.
- 사진·일기 카드와 사진 선택 동작에 접근성 역할과 구체적인 문구를 추가했다.

## 화면 원칙

- 사진 선택 전에는 기록을 생성하지 않는다.
- 사진과 일기는 내용을 눌러 다시 관리할 수 있게 한다.
- 첫 화면에서는 일기 3편과 사진 6장을 우선 보여 주고 나머지는 펼쳐 본다.
- 기념 카드는 기록을 복제하는 별도 데이터가 아니라 현재 사진과 사용자가 정한 문구를 조합한 결과물로 취급한다.
- 기록 통계는 현재 여행 안의 데이터만 기준으로 한다.

## 개발 단계로 넘기는 항목

- 기기 사진 권한 요청과 제한된 사진 접근 처리
- 원본은 기기에 두고 서버에는 최적화 이미지와 메타데이터를 저장하는 정책
- 사진 촬영일 메타데이터를 여행 일차로 자동 변환
- 사진 순서 변경과 기념 카드에 사용할 사진 선택
- 기념 카드 이미지 렌더링, 기기 저장 및 공유
- 전체 여행 통계와 여행별 통계 집계
- 사진 삭제 시 기기 원본은 삭제하지 않는 안전 정책
