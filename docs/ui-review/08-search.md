# 8단계 · 찾기

## 목표

현재 공간에 쌓인 여행·장소·일정·요리·준비·기록을 한곳에서 찾고, 원하는 유형으로 빠르게 범위를 줄인 뒤 관련 화면으로 이동할 수 있게 한다.

## 반영한 내용

- 검색 범위를 `모든 여행`이 아닌 현재 선택한 공간의 기록으로 명확히 표현한다.
- 한글과 영문 대소문자 차이를 무시해 제목, 여행명, 상세 정보와 태그를 검색한다.
- 키보드의 검색 버튼을 누르면 검색어가 최근 검색에 저장된다.
- 최근 검색어는 최신 순서로 최대 6개까지 유지한다.
- 최근 검색어를 개별 삭제하거나 전체 삭제할 수 있다.
- 최근 검색어가 없어도 영역을 유지하고 검색 후 저장된다는 안내를 보여 준다.
- 유형 필터마다 현재 검색어에 맞는 결과 수를 표시한다.
- 유형 필터와 장소 저장 상태에 접근성 선택 상태를 추가했다.
- 검색 결과에는 여행명, 유형, 상세 정보와 핵심 태그를 함께 표시한다.
- 결과를 누르면 해당 여행의 장소·준비·요리·기록 탭으로 이동한다.
- 장소 결과에서 저장 전환, 일정 추가 화면, 네이버 지도 검색으로 바로 이동한다.
- 실제 장소 정보가 자동 입력되지 않는 현재 단계에서는 `일정에 담기` 대신 `일정 추가`로 정확하게 표현한다.
- 검색어 삭제, 결과 열기와 빠른 동작에 구체적인 접근성 문구를 추가했다.

## 화면 원칙

- 최근 검색은 검색 결과와 관계없이 항상 검색창 아래에 둔다.
- 유형 탭은 가로 스크롤을 사용해 작은 화면에서도 항목 폭을 줄이지 않는다.
- 검색 전에는 현재 공간의 전체 기록을 보여 주고 검색 중에는 결과라는 제목을 사용한다.
- 결과가 없으면 검색어와 유형 필터를 한 번에 초기화할 수 있게 한다.
- 장소 외 유형은 결과 자체를 누르는 동작을 우선하며 불필요한 보조 버튼을 늘리지 않는다.

## 개발 단계로 넘기는 항목

- 로컬 데이터베이스의 전문 검색 또는 검색 인덱스
- 검색 결과와 실제 여행 데이터 ID 연결
- 장소 저장과 일정 추가 시 원본 장소 정보를 자동 입력하는 흐름
- 최근 검색어의 기기 로컬 저장과 개인정보 설정
- 검색 결과 정렬, 초성 검색과 오타 보정
- 많은 결과를 위한 페이지네이션 또는 점진적 로딩
