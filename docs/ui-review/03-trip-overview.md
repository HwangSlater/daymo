# 3단계 · 여행 상세·일정·교통·숙소

## 목표

여행을 만들 때 정한 기간을 상세 화면의 날짜 입력에 그대로 사용하고, 일정·교통·숙소가 서로 어떤 역할을 하는지 사용자가 혼동하지 않게 한다.

## 반영한 내용

- 선택한 여행의 시작일과 종료일을 상세 화면에 전달한다.
- 일정, 교통편, 체크인·체크아웃의 날짜 선택지를 해당 여행 기간으로 만든다.
- 새 일정은 선택한 날짜를 별도로 보존해 같은 요일이 반복되는 긴 여행에서도 수정할 날짜를 잃지 않게 한다.
- 가는 편은 여행 첫날, 오는 편은 마지막 날을 기본값으로 사용한다.
- 출발지와 도착지가 같거나 출발·도착 시간 중 한쪽만 입력하면 교통편을 저장하지 않는다.
- 체크아웃이 체크인보다 빠르거나 같으면 숙소를 저장하지 않는다.
- 한 여행에서 현재 대표로 보여 주는 숙소임을 문구로 명확히 했다.
- 예약 정보와 일정은 자동으로 같은 데이터가 되지 않는다는 안내를 추가했다.

## 화면 원칙

- 여행 기간 밖의 날짜를 다시 고르게 하지 않는다.
- 필수 입력이 부족할 때 완료 버튼은 막고, 무엇을 고쳐야 하는지 버튼 문구에서 바로 알려 준다.
- 교통편은 저장할 때 일정에도 이동 항목으로 추가하고, 예약은 사용자가 일정에 넣을지 선택할 수 있도록 관계를 설명한다.
- 대표 숙소는 장소 탭에서 숙소로 등록한 장소와 연결되는 대상으로 표현한다.

## 개발 단계로 넘기는 항목

- 일정·교통·숙소·예약에 고유 ID를 부여하고 서버 데이터로 연결
- 교통편 수정·삭제 시 자동 생성한 일정도 함께 갱신하는 연결 규칙
- 여러 숙소를 날짜별로 관리하고 그중 대표 숙소를 선택하는 모델
- 날짜와 시간을 기기 로케일에 맞는 네이티브 선택기로 입력
- 일정 정렬과 날짜별 그룹화

## 검수 결과

- TypeScript 타입 검사 통과
- 코드 공백 및 충돌 검사 통과
- 기존 3일 더미 여행과 다른 기간의 여행 모두 같은 날짜 생성 함수를 사용
