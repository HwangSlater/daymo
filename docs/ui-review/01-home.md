# 1단계 — 홈 UI 개선

## 목표

사용자가 앱을 열었을 때 다음 행동을 고민하지 않고 가장 가까운 여행과 필요한 준비로 이동할 수 있게 한다.

## 이번 단계에 포함

- 진행 중인 여행을 가장 먼저 표시한다.
- 진행 중인 여행이 없으면 시작일이 가장 가까운 예정 여행을 표시한다.
- 예정 여행이 없을 때 새 여행으로 이어지는 빈 상태를 제공한다.
- 상세 화면으로 이동하는 버튼 문구를 실제 동작과 맞춘다.
- 홈의 이동용 항목이 완료 체크박스로 오해되지 않게 한다.
- 연인 관계의 고정된 `함께한 날짜` 예시를 제거한다.

## 이번 단계에서 제외

- 일정·장소·준비 개수의 실제 데이터 계산
- 홈 카드 좌우 넘김
- 여러 임박 여행 동시 표시
- 서버에서 다음 여행을 조회하는 API

위 항목은 여행별 데이터 모델과 상세 데이터가 연결되는 개발 단계에서 진행한다.

## 완료 조건

- 여행 배열 순서와 관계없이 올바른 다음 여행을 선택한다.
- 예정 여행 0개 상태에서 잘못된 예시 여행이 노출되지 않는다.
- 홈의 모든 바로가기가 예상한 상세 탭으로 이동한다.
- 타입 검사와 iOS 시뮬레이터 검수를 통과한다.

## 결과

완료.

- 진행 중인 여행 또는 시작일이 가장 가까운 예정 여행을 자동 선택한다.
- 예정 여행이 없으면 새 여행 작성으로 바로 이어지는 빈 상태를 표시한다.
- 홈의 `전체 보기`를 실제 이동에 맞는 `여행 보기`로 변경했다.
- 홈 이동 항목의 체크박스 형태를 색인 표시로 바꿨다.
- 연인 관계의 고정된 일수 예시를 `둘만의 여행`으로 변경했다.
- 정상 상태와 여행 0개 상태를 iOS 시뮬레이터에서 확인했다.
