# 2단계 — 여행 목록·지도·캘린더 UI 개선

## 목표

사용자가 목록·지도·캘린더 사이를 이동해도 현재 보고 있는 기준을 이해하고, 새 여행을 만든 뒤 자연스럽게 상세 관리로 이어지게 한다.

## 이번 단계에 포함

- 예정 여행은 종료일이 오늘 이후인 여행으로 분류한다.
- 종료된 여행만 추억으로 분류한다.
- 캘린더는 현재 월을 기본으로 연다.
- 캘린더에 처음 진입하면 오늘 날짜를 선택한다.
- 선택 날짜를 다시 누르거나 `선택 해제`로 해제할 수 있다.
- 이전 달에 시작해 현재 월까지 이어지는 여행도 월간 범례에 포함한다.
- 지도에 확대 위치를 초기 상태로 돌리는 `전체` 동작을 제공한다.
- 새 여행의 종료일이 시작일보다 빠르면 저장을 막는다.
- 새 여행 생성 후 해당 여행 상세 화면으로 바로 이동한다.
- 목록 분류, 보기 탭, 지도 지역과 캘린더 날짜에 접근성 선택 상태를 제공한다.

## 이번 단계에서 제외

- 지도 행정구역 데이터 추가
- 지도 네이티브 엔진 교체
- 여러 여행의 캘린더 일정 제목 표시 방식 선택
- 여행 삭제·복제·보관
- 필터 상태의 기기 저장

## 확인한 상태

- 기본 목록 진입
- 캘린더 오늘 자동 선택
- 여행이 없는 날짜의 새 여행 동선
- 월간 여행 기간 연결 표시
- 선택 날짜 해제
- 타입 검사

## 결과

완료.
