# 개인정보·출시 준수 계획

> 이 문서는 2026-08-12 기준 개발 체크리스트이며 법률 자문을 대체하지 않는다. 공개 출시 전 대한민국 개인정보 전문 변호사 또는 전문기관의 최종 검토가 필요하다. 법령과 스토어 정책은 변경될 수 있으므로 제출 직전에 다시 확인한다.

초기 공개 출시 주체는 개인 개발자로 확정한다. 앱 UI, 예시 데이터와 공개 저장소에는 운영자의 실명을 넣지 않지만, App Store 판매자 정보와 개인정보 처리방침·이용약관·권리행사 연락처처럼 법적으로 필요한 영역에는 검증된 법적 이름과 실제 연락처를 사용한다. 개인 출시를 조직명으로 위장하지 않는다.

사용자에게 공개하는 문의·권리행사 이메일은 `support@daymo.xyz`로 통일하고 Daymo 전용 Google 계정으로 전달한다. 자동 인증·알림 발신 주소 `no-reply@daymo.xyz`는 회신 문의 주소로 사용하지 않는다. 도메인 구매와 수신 설정이 끝나기 전에는 공개 출시하지 않고 실제 수신·답변·스팸 분류를 시험한다.

## 2. 가입 화면의 동의 구조

### 한 번에 묶지 말아야 할 항목

- `[필수] 서비스 이용약관 동의`
- `개인정보 처리방침 확인`: 처리 근거가 계약 이행/법적 의무인지 별도 동의인지 구분
- `[선택] 마케팅 알림 수신`
- `[선택] 선택 분석/개인화`를 실제 도입하는 경우 별도 동의
- `[선택 또는 별도 고지] 개인정보 국외 이전`: 실제 이전 근거와 서비스 구성을 법률 검토 후 결정

‘전체 동의’는 제공할 수 있지만 선택 항목이 무엇인지 보여주고 각각 철회할 수 있어야 한다. 선택 동의를 거부했다는 이유로 여행 핵심 기능을 막지 않는다. 동의가 법적 근거가 아닌 필수 처리 정보는 억지로 체크박스를 만들기보다 처리방침과 가입 직전 핵심 고지로 투명하게 알린다.

동의/확인 기록에는 사용자, 문서 type/version, 시각, 결과, 당시 중요 내용의 hash를 저장한다. 원문은 변경 불가능한 version URL로 보존한다.

- 정보주체의 열람·정정·삭제·처리정지·동의철회 방법
- 개인정보 보호책임자 또는 담당 연락처, 피해구제 방법
- 자동 수집 항목과 거부 방법
- 안전성 확보조치
- 처리방침 변경 이력과 시행일

2024 개인정보보호위원회 작성지침을 기본 템플릿으로 사용하되 복사한 예시 문구를 실제 시스템과 다르게 두지 않는다.

개인정보 보호법 제28조의8은 국외 제공·처리위탁·보관을 규율한다. ConoHa를 포함해 물리적 처리 국가를 모르는 상태에서는 출시하지 않는다. 계약 이행을 위한 국외 처리위탁/보관 근거를 사용하는 경우에도 법정 사항의 처리방침 공개 또는 정해진 방식의 고지가 필요할 수 있으므로 전문가 검토를 받는다.

## 5. 시스템 권한

- 사진: 전체 사진 접근을 가입 시 요구하지 않는다. 사진 추가를 누른 시점에 system picker를 우선 사용한다.
- 카메라: 앱 내 촬영을 누른 시점에만 요청하고 거부 시 앨범 선택을 제공한다.
- 위치: 현재 기능은 지역 직접 선택과 지도 링크로 가능하므로 요청하지 않는다. 향후 현재 위치 기능을 추가할 때 별도 검토한다.
- 알림: 일정/담당 알림의 이점을 먼저 설명하고 사용자가 켤 때 요청한다. 거부해도 앱 사용 가능하다.
- 연락처·마이크·광고 ID: 현재 기능에 필요 없으므로 요청/수집하지 않는다.

iOS purpose string과 Android permission 설명은 구체적인 실제 용도로 작성한다. 앱 내부 동의와 OS 권한을 같은 것으로 취급하지 않는다.

## 6. 계정·공간·데이터 삭제

- 앱 설정에서 계정 삭제를 쉽게 찾을 수 있게 제공한다.
- 계정 삭제 요청 후 7일 유예하며 즉시 현재 session을 종료한다. 유예기간 안에는 재인증으로 취소할 수 있고 화면과 이메일에 최종 삭제 예정일을 표시한다.
- Apple 요구에 따라 단순 비활성화가 아니라 계정과 관련 개인정보 삭제를 시작할 수 있어야 한다.
- Google Play를 위해 앱 내부 경로와 외부 웹 삭제 요청 URL을 모두 제공한다.
- Sign in with Apple 사용자는 탈퇴 시 Apple token revoke를 수행한다.
- 탈퇴 전 ‘내 계정 삭제’와 ‘공동 공간/여행 삭제’를 구분한다.
- 다른 멤버와 공동 작성한 여행은 공간 소유권 이전 또는 작성자 비식별화 정책을 정한다.
- Daymo는 공동 여행 콘텐츠를 유지하고 작성자를 `탈퇴한 멤버`로 비식별화한다. 탈퇴 확인 전에 사용자가 본인이 업로드한 사진을 검토·삭제할 수 있는 진입점을 제공한다.
- 계정 탈퇴가 아닌 공간 나가기에서는 공동 콘텐츠와 작성자 이름을 유지한다. 나가기 전에 본인 사진을 검토·삭제할 기회를 제공하고 나간 뒤에는 해당 공간 접근을 차단한다.
- owner가 멤버를 내보내도 공동 콘텐츠와 작성자 이름은 유지하고 접근만 즉시 차단한다. 내보내기와 콘텐츠 일괄 삭제를 결합하지 않는다.
- 사진처럼 사용자를 식별할 수 있는 콘텐츠의 삭제 범위와 다른 멤버에게 미치는 영향을 확인창에서 설명한다.
- 사진 업로더는 본인 사진을 삭제·복구할 수 있고 공간 owner는 관리 책임상 모든 사진에 같은 권한을 가진다. 다른 editor는 타인 사진을 삭제할 수 없다.
- 삭제된 공동 메모와 사진은 7일간 휴지통에서 복원 가능하고 이후 운영 원본에서 최종 삭제한다.
- 법적 보존 대상이 없다면 지체 없이 파기하고, 백업은 복원 시 재삭제되도록 deletion ledger를 둔다.

마지막 owner 탈퇴와 공동 콘텐츠의 작성자 비식별화 정책은 확정했다. 다른 멤버가 올린 사진에 등장하는 사람의 삭제·처리정지 요청은 사진을 임시 숨긴 뒤 요청을 검토하고, 업로더·owner에게 최소 정보만 알린 다음 삭제 또는 복원한다. 신원·당사자성 확인 자료와 처리 기한은 공개 전 법률 검토로 확정한다.

## 7. 만 14세 미만

대한민국에서 만 14세 미만 아동의 개인정보 처리에는 법정대리인 동의 등 추가 절차가 문제될 수 있다. Daymo는 이용약관상 만 14세 이상만 가입 가능하게 하고 가입 시 연령 적격 확인을 받기로 결정했다. 생년월일 원본은 수집하지 않는다. 이 확인 방식의 실효성은 공개 출시 전 법률 검토를 받는다.

향후 아동 사용을 허용하려면 법정대리인 확인·동의·철회·권리행사와 아동 대상 스토어 정책까지 별도 기능으로 구현하기 전에는 정책을 변경하지 않는다.

## 8. 보안·운영 의무

- TLS, 비밀번호 Argon2id 단방향 hash, secret 분리, 최소 권한, 관리자 MFA
- DB/사진 암호화와 외부 암호화 백업
- 개인정보 관리자 접근 최소화와 접속기록 보존/위변조 방지
- 운영 로그 PII masking, 개발/스테이징에 실데이터 사용 금지
- 취약점/의존성 업데이트, rate limit, 로그인 시도 방어
- 개인정보 보호책임자/담당자와 내부 처리 절차 지정
- 유출 의심 탐지, 격리, 증거 보존, 영향 평가, 사용자 통지와 관계기관 신고 절차

유출 통지·신고 기준과 시간은 사고 당시 최신 법령/시행령을 확인한다. 사고 연락망과 통지문 템플릿을 배포 전에 준비한다.

## 9. App Store / Google Play

### Apple

- App Store Connect에 Privacy Policy URL과 App Privacy 답변 등록
- 앱 안에서도 처리방침을 쉽게 열 수 있어야 함
- 계정 생성 지원 시 앱 내 계정 삭제 시작 기능
- 소셜 로그인 제공 시 Apple guideline 4.8에 맞는 동등한 로그인 선택지 유지
- 사진/카메라는 목적 문자열과 기능 시점 요청
- 리뷰용 계정 또는 완전한 demo mode와 살아 있는 backend 제공

### Google Play

- 모든 배포 앱의 Data safety form을 실제 SDK/서버 처리와 일치시킴
- Privacy Policy URL 제공
- 계정 생성 시 앱 내 삭제와 외부 웹 삭제 요청 URL 모두 제공
- 데이터 유형, 수집/공유, 목적, 암호화, 삭제 방식을 정확히 신고
- 비공개/공개 테스트 track별 정책 적용 범위를 제출 시 재확인

Sentry, OAuth SDK, push SDK처럼 제3자 SDK가 수집하는 데이터도 스토어 신고 대상에서 누락하지 않는다.

## 10. 이용약관과 운영 정책

이용약관에는 최소한 서비스 목적, 계정·초대 공간, 사용자 콘텐츠 권리/책임, 금지행위, 서비스 변경·중단, 탈퇴/삭제, 책임 범위, 준거법·분쟁 해결, 운영자 연락처를 둔다.

- 사진·링크·메모를 올릴 권한과 타인의 사생활/저작권 침해 금지
- 초대받은 멤버가 공동 콘텐츠를 열람·수정할 수 있다는 설명
- 신고/문의와 긴급 삭제 절차
- 첫 출시부터 앱 내 사용자·콘텐츠 신고와 사용자 차단을 제공하고, 신고자 신원을 신고 대상에게 공개하지 않음
- 차단은 새 초대·공간 합류·관련 알림을 막고 기존 공동 공간은 나가기 또는 owner 내보내기로 정리
- 모든 신고는 즉시 접수하고 24시간 안에 최초 검토; 사진 노출·위협·아동 안전 긴급 신고는 우선 임시 제한
- 유료 기능을 추가하면 전자상거래, 환불, 인앱결제 정책을 새로 검토
- 지도/YouTube 링크와 로고 사용은 각 제공자의 이용약관·브랜드 가이드 준수
- 오픈소스 라이선스 고지 화면 또는 문서 제공
