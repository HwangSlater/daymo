# 13. 문구 사전

사용자에게 보이는 한국어 문구를 쓸 때 따르는 기준이다. 2026-09-17 에 앱 전체 문구를
카카오톡·네이버·토스·당근·인스타그램·삼성 갤러리·구글 포토·트리플의 관행과 견줘 정리했다.
새 문구를 쓰기 전에 이 표에서 같은 개념을 찾고, 없으면 여기에 먼저 추가한다.

## 용어

| 개념 | 쓰지 않는 말 | 쓰는 말 |
|---|---|---|
| 없애기 | 지우기, 폐기, 떼기, 버리기, 치우기 | **삭제**. 제목 「~을 삭제할까요?」, 버튼 「삭제」, 토스트 「삭제했어요」. 목록에서만 빼는 것은 「빼기」 |
| 새로 넣기 | 등록, 적기, 넣기 | 항목은 **추가**, 여행·카드 같은 결과물은 **만들기** |
| 지정 / 지정 취소 | 등록/해제, 홈에 쓰기, 깔기, 내리기 | **~으로 설정** / **설정 해제** (대표 숙소, 대표 사진) |
| 내용 바꾸기 | 고치기, 편집(라벨), 변경 저장 | 라벨·메뉴 **수정**, 시트 제출 버튼 **저장**, 설정값은 **바꾸기**, 편집기 왼쪽 위 **취소** / 오른쪽 위 **완료** |
| 카드 편집 진입 | 꾸미기(사진에서), 고치기 | 사진 볼 때 **카드 만들기**, 만든 카드는 **카드 꾸미기** |
| 사진 묶음 | 기념 카드, 여행 기념 카드 | **추억 카드**. 첫 언급·빈 화면은 「추억 카드」, 버튼·토스트는 「카드」 |
| 사진을 화면 가득 모아 보기 | 사진첩 열기, 더 보기(사진), 갤러리 | 기록 탭 격자 아래 **사진 N장 모두 보기**. 열린 화면 머리는 여행 이름 |
| 여러 장 고르기 | 편집, 다중 선택, 체크, 골라 담기 | 머리 오른쪽 **선택** → 머리 「**N장 선택**」과 「**취소**」, 날짜 줄 **전체 선택 / 선택 해제**, 아래 줄 **삭제 · 저장 · 카드로 만들기**(고른 사진으로 카드를 시작할 때만 「카드로」). 한꺼번에 지운 뒤 알림 「사진 N장을 삭제했어요」의 버튼은 **되돌리기** |
| 여행 대표 이미지 | 홈 화면 사진, 홈에 쓰기, 커버 | **대표 사진** |
| 그룹 단위 | 그룹 | 화면 제목·첫 등장은 **여행 공간**, 버튼·행·문장 속은 **공간** |
| 사람 | 함께하는 사람(라벨), 이용자 | 공간 소속 **멤버**, 이번 여행은 **참가자**, 교통편은 **타는 사람**. 문장 속 「사람」은 허용 |
| 권한 | 보기만 | **관리자 · 편집 가능 · 보기 전용** |
| 기기에 사진 저장 | 내려받기, 받기, 다운로드 | **저장** |
| 서버로 보내기 | 올리는 중, 못 올린, 저장 안 됨 | **업로드 중** / **업로드 실패** |
| 가져오기 | 받는 중, 받아 오는 중 | **불러오는 중** / **불러오지 못했어요** |
| 원본 만료 뒤 화질 | 화면 크기, 표시본 | 「원본 보관 기간(30일)이 지나 **줄인 화질**로 저장돼요」 |
| 텍스트 요소 | 글, 글자, 문구 | 도구·탭은 **텍스트**, 카드의 문구 칸은 **한 줄 설명** |
| 카드 틀 | 틀, 모양, 없음 | **프레임**, 기본값은 **기본** |
| 사진↔장소·일정 관계 | 붙이기, 걸어 두기 | **연결** |
| 다른 기기 로그인 끊기 | 해지, 끊기, 정리 | **로그아웃** |
| 본인 재확인 | 다시 로그인해 확인, 다시 한 번 확인 | **본인 확인** |
| 비밀번호 되찾기 | 찾기, 다시 정하기 | 진입 「비밀번호를 잊으셨나요?」, 화면·메일 **비밀번호 재설정** |
| 이메일 소유 확인 | 이메일 인증 | **이메일 확인** |
| 오류 원인 | 서버, 연결, 동기화, 세션, 토큰 | **인터넷 연결**. 구현 용어는 사용자 문구에 쓰지 않는다 |
| 저장한 장소 | 저장 장소, 담아 둔 장소, 담아 둔 곳 | **저장한 장소**. 상태는 **후보 · 일정에 담김 · 다녀옴** |
| 돈 | 쓴 돈(제목) | 탭 **비용**, 항목 **지출**, 합계 **총 지출**, 나눔 **몫** |
| 지출을 셈에서 빼되 남기기 | 비활성화, 숨기기, 끄기, 무시 | 토글 **정산에서 빼기** / 되돌리기 **정산에 넣기**, 목록·표의 상태 표시 **정산 제외** |
| 낸 사람 혼자 몫 | 개인 지출, 혼자 내기, 자기 부담 | 나누기 방식 **본인 부담** |
| 여행 분류 | 예정, 추억 | 카드 「여행 중 / 지난 여행 / 다가오는 여행」, 필터 **다가오는 · 지난 여행 · 보관**. 삭제 대기는 **휴지통** |
| 빈 값 | 미등록, 아직 없음(칩) | 칩·값 자리는 **미정**, 문장 자리는 **아직 없어요** |
| 강퇴 / 파일 저장 | 내보내기(파일) | 강퇴는 **내보내기**, 파일은 **여행 기록 저장하기** |
| 계정 없애기 | 회원 탈퇴, 탈퇴한 멤버 | **계정 삭제**, 남는 이름표는 **삭제된 계정** |
| 시각 | 오전·오후, 午後, 7시 30분(목록·카드) | **24시간** `19:30`. 일정·교통편·예약·캘린더·카드 모두 같다. 고르는 칸(`ui/TimeWheel.tsx`)도 24시간이다. 같은 시각이 화면마다 두 가지로 보이지 않게 한다(2026-09-18) |
| 앱에 대한 말 | 피드백, 건의, 제안 | 앱 안에서 쓰는 것은 **의견 보내기**(종류 칩 **불편해요 · 이런 기능이 있으면 · 기타**), 메일은 **문의하기** |
| 시트의 접힌 선택 칸 | 더 보기, 자세히, 세부 정보, 펼치기 | 접혀 있을 때 **＋ 장소 · 메모 더 적기**(칸 이름을 가운뎃점으로 잇는다), 펼쳐진 뒤 **장소 · 메모 접기**. 「적기」는 여기서만 쓴다 |

## 문장 규칙

- 어미는 **~해요 / ~해 주세요**. 「~하세요」「~합니다」「~보여드리고 있어요」는 쓰지 않는다.
- 문어체 「되었」「하였」 대신 「됐」「했」.
- 보조용언은 띄어 쓴다: 「적어 보세요」「남겨 보세요」.
- 입력칸 라벨에 「· 필수」를 붙이지 않는다. 선택 칸만 **(선택)**. placeholder 는 「예: …」 형태.
- 확인 대화상자: 제목은 질문형 한 줄(「이 사진을 삭제할까요?」), 본문은 결과와 되돌릴 수 있는지(「휴지통에서 7일 안에 되돌릴 수 있어요」), 버튼은 짧은 동사(「취소」「삭제」).
- 오류는 **무엇이 잘못됐는지 + 다음에 할 일** 한 문장씩. 「잠시 후 다시 시도해 주세요」.
- 조사는 `josa()` 로 붙이거나 「OO 님을」처럼 고정되게 쓴다. 「을(를)」 병기는 쓰지 않는다.
- 같은 입력칸은 어디서나 같은 placeholder. 같은 상황의 안내는 한 문장으로.
- 「N개의 여행」이 아니라 「여행 N개」.
- 버튼 이름은 「버튼」이지 「단추」가 아니다.
