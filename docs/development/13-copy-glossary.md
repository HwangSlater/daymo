# 13. 문구 사전

사용자에게 보이는 한국어 문구를 쓸 때 따르는 기준이다. 2026-09-17 에 앱 전체 문구를
카카오톡·네이버·토스·당근·인스타그램·삼성 갤러리·구글 포토·트리플의 관행과 견줘 정리했다.
새 문구를 쓰기 전에 이 표에서 같은 개념을 찾고, 없으면 여기에 먼저 추가한다.

## 용어

| 개념 | 쓰지 않는 말 | 쓰는 말 |
|---|---|---|
| 없애기 | 지우기, 폐기, 떼기, 버리기, 치우기 | **삭제**. 제목 「~을 삭제할까요?」, 버튼 「삭제」, 토스트 「삭제했어요」. 목록에서만 빼는 것은 「빼기」 |
| 새로 넣기 | 등록, 적기, 넣기 | 항목은 **추가**, 여행·카드 같은 결과물은 **만들기** |
| 지정 / 지정 취소 | 등록/해제, 홈에 쓰기, 깔기, 내리기 | **~으로 설정** / **설정 해제** (대표 숙소, 대표 사진) |
| 내용 바꾸기 | 고치기, 편집(라벨), 변경 저장 | 라벨·메뉴 **수정**, 시트 제출 버튼 **저장**, 설정값은 **바꾸기**, 편집기 왼쪽 위 **취소** / 오른쪽 위 **완료**. 나가도 바뀐 것이 그대로 남는 편집기(카드 꾸미기)만 왼쪽 위가 **닫기** — 「취소」는 무른다는 뜻으로 읽힌다(2026-09-23) |
| 카드 편집 진입 | 꾸미기(사진에서), 고치기 | 사진 볼 때 **카드 만들기**, 만든 카드는 **카드 꾸미기** |
| 사진 묶음 | 기념 카드, 여행 기념 카드 | **추억 카드**. 첫 언급·빈 화면은 「추억 카드」, 버튼·토스트는 「카드」 |
| 아직 완료하지 않은 카드 | 초안, 임시 저장, 작성 중, 편집 중 | 격자 칸의 표는 **꾸미는 중**(대표 표시와 같은 모양). 코드·문서에서는 「초안」이라 부르되 화면에는 쓰지 않는다 |
| 카드 완료 | 저장, 내보내기, 공유, 사진으로 만들기 | 머리줄 버튼 **완료** → 확인 창 「**카드를 완료할까요?**」 / 「**완료하면 더 고칠 수 없어요. 여행 기록에 사진으로 저장돼요.**」 / 「취소」「완료」 → 토스트 「**사진으로 저장했어요**」(버튼 「보기」). 덮개 글은 「사진으로 저장하는 중이에요」 |
| 카드 초안 없애기 | 버리기, 취소 | 도구 ⋮ 의 **카드 삭제** → 「**이 카드를 삭제할까요?**」 / 「**카드만 삭제되고 사진은 그대로 남아요.**」 / 「취소」「삭제」 → 「카드를 삭제했어요」. 꾸미다 「닫기」로 나가는 것은 묻지 않고 초안을 남긴다 |
| 사진을 화면 가득 모아 보기 | 사진첩 열기, 더 보기(사진), 갤러리 | 기록 탭 격자 아래 **사진 N장 모두 보기**. 열린 화면 머리는 여행 이름 |
| 여러 장 고르기 | 편집, 다중 선택, 체크, 골라 담기 | 머리 오른쪽 **선택** → 머리 「**N장 선택**」과 「**취소**」, 날짜 줄 **전체 선택 / 선택 해제**, 아래 줄 **삭제 · 저장 · 카드로 만들기**(고른 사진으로 카드를 시작할 때만 「카드로」). 한꺼번에 지운 뒤 알림 「사진 N장을 삭제했어요」의 버튼은 **되돌리기** |
| 여행 대표 이미지 | 홈 화면 사진, 홈에 쓰기, 커버 | **대표 사진** |
| 그룹 단위 | 그룹 | 화면 제목·첫 등장은 **여행 공간**, 버튼·행·문장 속은 **공간** |
| 사람 | 함께하는 사람(라벨), 이용자 | 공간 소속 **멤버**, 이번 여행은 **참가자**, 교통편은 **타는 사람**. 문장 속 「사람」은 허용 |
| 권한 | 보기만 | **관리자 · 편집 가능 · 보기 전용** |
| 기기에 사진 저장 | 내려받기, 받기, 다운로드 | **저장** |
| 폰에서 저장이 끝났을 때 | 사진 N장을 저장했어요(폰), 공유했어요 | 폰은 OS 저장 창을 열어 준 것까지만 알 수 있으니 **됐다고 말하지 않는다**. 빠진 것만 「사진 N장은 저장하지 못했어요」 「업로드 중인 N장은 뺐어요」. 「사진 N장을 저장했어요」는 웹에서만 쓴다(`gallerySelection.savedText`, 2026-09-23) |
| 받아 둔 사진 파일 | 캐시, 임시 파일, 저장 공간 | 설정의 줄 이름은 **사진 캐시**, 버튼은 **비우기**, 크기는 「사진 캐시 128MB」처럼 숫자만(`photoCachePlan.cacheSizeText`). 「비우면 다시 볼 때 다시 받아요」 (2026-09-23) |
| 로그인이 저절로 풀렸을 때 | 세션 만료, 토큰 만료, 인증이 만료됐어요 | **「로그인이 풀렸어요. 다시 로그인해 주세요」** 한 줄. 기한이 지난 것, 다른 기기에서 로그아웃시킨 것, 계정이 사라진 것을 가리지 않는다 — 할 일이 같다(`auth.takeSessionEndNotice`, 2026-09-23) |
| 서버로 보내기 | 올리는 중, 못 올린, 저장 안 됨 | **업로드 중** / **업로드 실패** |
| 가져오기 | 받는 중, 받아 오는 중 | **불러오는 중** / **불러오지 못했어요** |
| 못 불러온 뒤 다시 받기 | 새로고침, 재시도, 다시 불러오기(버튼) | 버튼은 **다시 시도**. 기다리는 줄은 「**불러오는 중이에요**」, 실패한 줄은 무엇을 못 불러왔는지 적는다(「휴지통을 불러오지 못했어요」). `ui/LoadState` 의 기본값이다 (2026-09-23) |
| 원본 만료 뒤 화질 | 화면 크기, 표시본 | 「원본 보관 기간(30일)이 지나 **줄인 화질**로 저장돼요」 |
| 텍스트 요소 | 글, 글자(라벨), 문구 | 도구·탭·접근성 라벨은 **텍스트**, 카드의 문구 칸은 **한 줄 설명**. 낱글자를 셀 때(「20자까지」)만 「글자」를 쓴다. 저장값 `kind: "글자"`(`cardDecor.ts`)와 `Stage: "고치기"` 같은 내부 값은 그대로 둔다 — 화면에 보이는 라벨만 바꾼다 |
| 카드 위에 얹기 | 붙이기, 추가(카드) | **카드에 넣기**. 「넣다」는 카드·정산처럼 이미 있는 그릇에 담을 때만 쓰고, 목록에 새 줄을 만드는 것은 **추가**다(「이 여행에 추가」, 「영수증 추가」) |

| 사진↔장소·일정 관계 | 붙이기, 걸어 두기 | **연결** |

| 비밀번호 되찾기 | 찾기, 다시 정하기 | 진입 「비밀번호를 잊으셨나요?」, 화면·메일 **비밀번호 재설정** |
| 이메일 소유 확인 | 이메일 인증 | **이메일 확인** |

## 문장 규칙

- 어미는 **~해요 / ~해 주세요**. 「~하세요」「~합니다」「~보여드리고 있어요」는 쓰지 않는다. **「~해 두세요」는 쓴다** — 「해 두다」는 보조용언이고 「~세요」가 아니라 「~해 주세요」와 같은 결이다(「먼저 저장해 두세요」).
- 상대를 높이지 않는다. 「받아 오셨어요」→「받았어요」, 「보여 드릴게요」→「보여 줄게요」, 「정산해 드려요」→「정산해요」. 「저희」 대신 주어를 빼거나 「우리」.
- 느낌표는 쓰지 않는다: 「짐 꾸리기 완료!」가 아니라 「짐 꾸리기 완료」.
- 문어체 「되었」「하였」 대신 「됐」「했」.
- 보조용언은 띄어 쓴다: 「적어 보세요」「남겨 보세요」「꾸려 볼까요」「펼쳐 보는」. 한 낱말로 굳은 「붙여넣기」「물어보다」는 붙여 쓴다.
- 입력칸 라벨에 「· 필수」를 붙이지 않는다. 선택 칸만 **(선택)**. placeholder 는 「예: …」 형태. **비밀번호 칸만 예외** — 보기를 들 수 없으니 할 일을 적는다(「8자 이상 입력」「한 번 더 입력」「지금 쓰는 비밀번호」).
- 확인 대화상자: 제목은 질문형 한 줄(「이 사진을 삭제할까요?」), 본문은 결과와 되돌릴 수 있는지(「휴지통에서 7일 안에 되돌릴 수 있어요」), 버튼은 짧은 동사(「취소」「삭제」).
- 오류는 **무엇이 잘못됐는지 + 다음에 할 일** 한 문장씩. 「잠시 후 다시 시도해 주세요」.
- 조사는 `josa()` 로 붙이거나 「OO 님을」처럼 고정되게 쓴다. 「을(를)」 병기는 쓰지 않는다.
- **금액 뒤에는 조사를 붙이지 않는다.** 외화는 숫자·기호로 끝나 `josa()` 도 가릴 수 없다(「$12.52을」). 「지출을 추가했어요 · 식비 12,000원」처럼 금액을 뒤로 뺀다(2026-09-23, `tripExpenses.test.ts`).
- 같은 입력칸은 어디서나 같은 placeholder. 같은 상황의 안내는 한 문장으로. 이름 「예: 하늘」, 여행지 「예: 제주 애월」, 공간 이름 「예: 우리의 여행」.
- 도움말이 화면의 라벨을 인용할 때는 그 화면에 실제로 적혀 있는 말을 쓴다(참가자는 「이번 여행 참가자」).
- 「N개의 여행」이 아니라 「여행 N개」. 기간은 「7일간」이 아니라 「7일 동안」.
- 빈 값은 「내용 없음」「설명 없음」「제목 없음」처럼 `없음` 으로 끝맺는다. 서버로 가는 값(`빈 메모`)은 건드리지 않는다.
- 버튼 이름은 「버튼」이지 「단추」가 아니다.

## 검사가 걸러 주는 것

`mobile/src/copyGlossary.test.ts` 의 금지 패턴이 따옴표 안과 JSX 태그 사이의 글자를 본다(주석·변수 이름은 보지 않는다).
2026-09-23 에 「지우기·~하세요·~셨어요·드려요·저희·받는 중·쓴 돈·고치기·편집·카톡·붙여 넣·잠시 뒤·이 날·다시하기·N일간·보조용언 붙여쓰기·`${…}` 뒤 고정 조사」를 더했다.

- 꼭 남겨야 하는 문구는 **그 줄 끝에** `문구-사전-예외: 까닭` 을 적는다. 윗줄에 적으면 걸러지지 않는다.
- 지금 있는 예외: 「비밀번호를 잊으셨나요?」(이 사전이 정한 말), `noticeImportPlan.ts` 의 `${head}를`(`head` 가 늘 「… N개」로 끝난다).
- 저장값·서버로 가는 값은 패턴을 넓힐 때 반드시 빼 둔다: `cardDecor` 의 `kind: "글자"`, `SplitMode "균등"|"일부"`, 교통·예약 표, `MainView`, 카드 비율 이름, 메모의 `빈 메모`.
