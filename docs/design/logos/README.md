# 소셜 로그인 로고

소셜 로그인 콘솔에 올리는 Daymo 로고. 앱에 들어가지 않는다. 앱 아이콘과 같은 그림이고
`mobile/scripts/build-icons.py` 가 아이콘과 함께 다시 만든다. 손으로 고치지 않는다.

| 파일 | 올리는 곳 | 요구 |
| --- | --- | --- |
| `daymo-logo-google-120.png` | Google Auth Platform → 브랜딩 → 앱 로고 | 정사각 120px, JPG·PNG·BMP, 1MB 이하 |
| `daymo-logo-naver-140.png` | NAVER Developers → 애플리케이션 → 로고 이미지 | 140×140, JPG·PNG·GIF |
| `daymo-logo-kakao-128.png` | Kakao Developers → 앱 → 앱 아이콘 | 128×128 이하 권장, 250KB 미만 |

동의 화면이 로고를 원이나 둥근 사각형으로 잘라서, 그림은 가운데 원 안에 맞춰 두었다.
Google 은 운영(프로덕션) 상태에서 로고를 올리면 브랜드 인증을 거쳐야 동의 화면에 보인다.
Apple 은 따로 올리는 로고가 없다.
